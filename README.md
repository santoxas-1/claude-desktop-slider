Автономный визуальный мод для десктопного приложения **Claude Desktop**, добавляющий эффект **звёздного гиперпрыжка (Warp Speed)** в слайдер управления глубиной рассуждений (Reasoning Effort).

---

## 🌟 Особенности (Features)

- **Аппаратное ускорение на GPU (Compositor Thread)**: Анимация работает напрямую через видеокарту на CSS 3D-трансформациях. 0% нагрузки на процессор, монолитные 60/120/144+ FPS без лагов и задержек.
- **Активация строго на «Максимум»**: На обычных режимах (*Низкий*, *Средний*, *Высокий*) слайдер остаётся 100% нативным и чистым. Звёзды и космический разгон просыпаются только при включении режима **«Максимум»**.
- **Физика поглощения (Absorption)**: Звёзды летят слева направо строго до положения бегунка и плавно растворяются в его ядре. Правее бегунка звёзд нет.
- **Фирменный стиль Claude Code**: Тёплый оранжево-терракотовый неоновый ореол сверхновой на бегунке и искрящиеся золотисто-оранжевые световые лучи.
- **100% нативный трек**: Дорожка слайдера сохраняет свой оригинальный цвет и форму без лишних цветных рамок.
- **Установка, обновление и откат в 1 клик**: Никаких консолей или ручного редактирования кода.

## 📥 Установка (Installation)

### 🪟 Windows (в 1 клик)
1. Скачайте архив репозитория (кнопка **Code → Download ZIP** или релиз).
2. Распакуйте архив в любую удобную папку.
3. Запустите файл **`install.bat`** двойным кликом.
4. Перезапустите Claude Desktop (или нажмите `Ctrl + R` в его окне).

### 🍎 macOS / 🐧 Linux
Откройте терминал в папке мода и выполните:
```bash
chmod +x install.sh
./install.sh
```

## 🔄 Обновление (Update)

Если вышло обновление мода или само приложение Claude Desktop обновилось и перезаписало файлы:

- **Windows**: Запустите **`update.bat`** двойным кликом. Скрипт проверит наличие новой версии файла с GitHub и заново подключит мод в один клик.
- **macOS / Linux**: Выполните `./update.sh`.

---

## 🗑️ Удаление (Uninstall)

Мод полностью обратим и не повреждает файлы приложения:

- **Windows**: Запустите **`uninstall.bat`** двойным кликом. Скрипт мгновенно восстановит оригинальный интерфейс Claude Desktop из резервной копии.
- **macOS / Linux**: Выполните `./uninstall.sh`.

---

## ⚙️ Тонкая настройка (Customization)

Все параметры мода собраны в файле `cosmic-slider.js`:

- **Количество звёзд**: строка `const numStars = 32;`
- **Скорость полёта**: параметр `duration = (0.36 + Math.random() * 0.2)`
- **Цвета лучей**: массив `starConfigs` в функции `createGpuStarfield()`
- **Цвет свечения бегунка**: правило `@keyframes cosmic-claude-orange-glow`

После изменения файла достаточно нажать `Ctrl + R` в окне Claude Desktop.
